# 底图配置

底图列表定义在 `src/views/config.ts` 的 `BASE_MAPS` 数组中。右上角工具栏会自动读取这个数组，在 2D／3D 按钮下方生成底图入口；点击后在左侧选择底图。

默认提供卫星影像、街道地图、无底图。数组的第一项是初始底图，调整顺序即可修改默认值。可直接增加或删除数组项，无需修改组件。每个 `id` 必须唯一。

## 添加底图

在 `BASE_MAPS` 中追加：

```ts
{
  id: 'my-map',
  name: '自定义底图',
  description: '可选的说明文字',
  options: {
    urlTemplate: 'https://your-tile-server.example/{z}/{x}/{y}.png',
    attribution: '© 地图服务提供方',
    crossOrigin: 'anonymous',
    maxAvailableZoom: 18,
  },
},
```

- `id`：底图唯一标识。
- `name`：弹窗内显示的名称。
- `description`：可选说明。
- `options`：Maptalks `TileLayer` 的配置，直接传给图层构造函数。支持 `urlTemplate`、`subdomains`、`tileSize`、`maxAvailableZoom`、`tileSystem` 等选项。
- `options: null`：不显示底图，仍保留保护区图层。

示例地址是占位符，需要替换为实际可访问的服务。当前地图使用 `EPSG:3857`；新增地图应使用与之匹配的瓦片坐标和投影，不能直接混用存在坐标偏移的瓦片。带鉴权或子域名的服务请按提供方要求配置。自定义服务需要支持浏览器跨域请求。

`attribution` 会显示在地图左下角边缘，随底图同步更新；它支持 HTML，请仅填写可信的本地配置。内置在线底图需要联网，正式使用时请确认服务方的授权、署名、访问限额等要求。

## 与保护区的关系

底图切换只替换地图的底图图层，不重建保护区，也不改变中心、缩放、二维／三维视角或已选分区的拔高状态。

保护区拔高后的顶面与当前底图共用瓦片源，不再单独配置影像地址。切换底图后立即移除旧源贴图，暂时显示分区颜色；新贴图加载完成后自动替换。选择“无底图”时保留纯色顶面。

顶面复用当前 `TileLayer.getTileUrl()`，支持字符串／函数式 `urlTemplate`、`subdomains`、`customTags` 和 URL 中的 `token`。地理范围按底图实际分辨率与瓦片尺寸计算，`zoomOffset` 仅作用于请求层级，与 Maptalks 的网格层级保持区分，避免 512 像素瓦片错位。顶面层级跟随底图，并遵守 `maxAvailableZoom`；纹理超过容量上限时可降到同源的较低可用层级。

目前支持全球 `EPSG:3857`、西北原点、向右／向下编号、正方形瓦片和二倍分辨率金字塔。其他投影、自定义原点／坐标方向、像素偏移、自定义着色器以及非空 `fetchOptions` 暂不自动适配，顶面会保留分区颜色并在图例状态栏提示；底图本身仍使用原配置。

纹理请求默认使用 `crossOrigin: 'anonymous'`，也可配置服务要求的跨域凭证模式。网络失败、请求超时、缺失瓦片或跨域不可用时，对应顶面保留分区颜色，不回退到卫星影像。修正配置、切换底图或再次操作地图可触发重新加载。

切换时使旧请求失效、取消旧源队列并释放纹理；只保留当前源的应用缓存。`RASTER_TOP_CONFIG` 仅控制并发、超时、缓存和纹理容量等性能参数。
