# 保护区列表

左上角列表按保护点分组，展开后显示功能分区。支持按名称、物种、城市、区县和编号搜索，多个关键词用空格分隔。搜索仅影响列表，不修改图层或地图选择。

## 操作

- 点击保护点名称：展开分区并定位到整个保护点；切换到另一保护点时取消原分区锁定。
- 点击右侧箭头：仅展开或收起分区，不移动地图。
- 点击分区：定位并锁定拔高，右下角显示详情；重复点击只重新定位，不取消锁定。
- 标记为“已隐藏”的分区仍可点击：自动打开保护区总开关和该分区所属类型，其他类型开关保持不变。
- 点击地图分区：列表同步高亮、展开对应保护点，并在当前搜索结果内滚动到对应行。
- 点击地图空白处：取消高亮、拔高和详情，保留列表搜索与展开状态。
- 屏幕宽度不超过 900px 时，列表默认收起，点击定位条目后也会收起，给地图让出空间。

列表和图例共用左侧可用高度，列表内部滚动。定位根据实际多边形范围计算，并为列表、图例和详情预留空间；保持底图、2D／3D、倾角和朝向不变。

## 数据与联动

`src/views/data/protectAreas.ts` 是列表和地图的共享入口：为原始要素分配固定 ID，按 `BHDBM` 分组，计算分区和保护点范围。列表筛选不会重新编号。新增数据后会自动参与列表分组。

`ProtectAreaView` 发出带递增编号的 `AreaRequest`；`MapScene` 仅保存最新请求。在地图初始化或图例重建完成后，通过 `onMeshesReady` / `onReady` 执行请求，不使用固定延时猜测网格是否可用。

保护区图层通过 `selectFeature(id)` 查找已创建网格，不再依赖 Vue 对象引用相等。地图回传的选择只用于更新列表和详情，不会再次发出定位请求。地图点击和导航工具操作会取消尚未执行的列表请求。

## 飞行动画

列表定位由 `useMapFlight` 的 GSAP 时间线驱动。同一保护点的近距离切换使用短动画；远距离切换同时平移和拉远，再缓慢靠近目标。保持底图、倾角与朝向，重复点击已到位目标不会重新飞行。

`getFocusView` 只读计算最终视图：使用真实范围、分数缩放和面板留白，通过地图坐标转换处理当前倾角与朝向下的中心偏移，不通过临时移动地图来获取参数。

连续点击会终止旧飞行，从当前实际位置转向最新目标。拖拽、滚轮、触摸、导航按键、地图点击、导航控件和地图尺寸变化会中断飞行；隐藏当前分区也会取消定位。原生地图动画在交接时被替换为当前视图的空动画并取消，避免直接取消原生动画时跳到旧终点。

飞行期间暂停鼠标悬停反馈，不影响已选择分区的拔高和详情。顶面贴图按间隔节流，到达或中断后立即刷新；切换底图仍使用原有请求失效机制。启用系统“减少动态效果”时直接定位。

`src/views/config.ts` 中的 `MAP_FLIGHT_CONFIG` 集中配置时长（单位为秒）、缓动、远距离阈值（相对于视口短边）、最大拉远级数、到位容差和贴图刷新间隔（单位为毫秒）。导航控件继续使用原生地图动画，与列表飞行互斥。
